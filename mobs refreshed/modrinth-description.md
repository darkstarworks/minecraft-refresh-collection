### 29 Refreshed Mobs
This resource pack completely refreshes most Hostile mobs with brand new designs, shading, and extra models.

<br>

## What's been done

- Works on **Minecraft 26.2 and 26.3** from one download
- Fixed MANY things that were broken or not behaving as intended
- Works on any Minecraft launcher - it is a plain resource pack, no mod loader needed

## How to use it

Drop the `.zip` into your `resourcepacks` folder, then turn it on in **Options > Resource Packs**. That is all.

**Want the custom body shapes too?** The pack also carries a set of optional model files. 

To see the reshaped mobs as well, use **OptiFine** or **Entity Model Features (EMF)** if you are on Fabric.
